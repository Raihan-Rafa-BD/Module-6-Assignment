**Project Description:**
This project is a simple personal profile webpage created using HTML. 
It introduces basic personal information, skills, hobbies, and contact details in a clean and organized layout.

**Objectives:
  To practice HTML Structural Tags, Text Formatting, Forms, Tables, Multimedia,
  Semantic Elements, and Interactive Elements.   

**Technologies Used**
    HTML5 — To create the structure and content of the webpage.

**Project Structure**:
personal-profile
│
├── index.html
└── README.md

**How to Run the Project:
    Download or clone this repository.
    Open the project folder.
    Open the index.html file in any web browser.
    View your personal profile webpage.
